# 판정 검증 자료

GPT 판정을 사람의 판단과 비교한 자료다. 공고 원문 전체는 경력개발센터 로그인 전용이라 넣지 않았다. 공고 id와 판정, 그리고
최종 실행(`final_*.tsv`)에는 판정 근거로 GPT가 인용한 회사·제목·업무·자격 문구가 짧게 들어 있다.
id로 경력개발센터에서 원문을 찾을 수 있다(`.../internship/view?id=<id>`, 로그인 필요).

| 파일 | 내용 |
|---|---|
| `labels.txt` | 정답 라벨 40건 — 개발자 본인이 직무만 보고 관심·애매·없음을 붙였다(GPT 판정을 보기 전에) |
| `gpt_2026-10-26_run3.tsv` | 학적 선택 도입 전 지침 |
| `gpt_2026-10-28_bbagi.tsv` · `gpt_2026-10-28_pyosi.tsv` | 학적 빼기/표시만 도입 직후 지침 |
| `gpt_2026-10-28_final_bbagi.tsv` · `gpt_2026-10-28_final_pyosi.tsv` | Codex 1차 검토 반영 지침(v0.1.2). 공고별 판정 이유 포함 |
| `compare.py` | 라벨과 판정의 교차표 |

```
python eval/compare.py eval/labels.txt eval/gpt_2026-10-28_final_bbagi.tsv
```

## 실행 조건

- 공고: 2026-10-26에 수집한 40건(공고 파일 2개, 20건씩) + 포스터 PDF 66쪽
- 기준: `gpt/기준 템플릿.md`(학적만 빼기/표시만으로 바꿈)
- GPT: ChatGPT Edu 공유 GPT 미리보기, 모델 6 · 추론 High(10-26 run3는 추론 수준 기록 없음), 코드 인터프리터 켬
- 메시지: "판정해줘. 오늘 날짜는 2026-10-26로 보고 마감을 판단해." — 수집일 기준으로 마감을 보게 했다

## 읽을 때 주의

- 라벨은 **사람 1명**(개발자 본인)의 판단이다. 다른 학생의 기준에서도 같은 성능이 나온다는 근거는 아니다.
- 지침을 고칠 때 이 40건의 결과를 보고 고쳤다(학적 선택, 휴학생 단서 규칙). 그래서 이 숫자는 처음 보는 공고에 대한 성능보다 좋게 나올 수 있다.
  새 공고 묶음으로 다시 재는 것이 다음 할 일이다.
- 같은 입력으로 다시 돌려도 판정이 조금씩 달라질 수 있다(10-26 run3와 10-28 빼기는 40건 모두 같았다).
