# SNU InternWatch

서울대 경력개발센터 인턴 게시판의 새 공고를 **내 기준으로** 골라 주는 도구.
수집 북마크가 공고를 파일로 모으고, ChatGPT Edu 공유 GPT가 그 파일을 읽어 추천·참고·직접 확인·제외로 나눈다.

- 북마크 설치: https://sinabro-2004.github.io/snu-internwatch/
- InternWatch GPT: (공개 후 링크 추가)

## 쓰는 법

1. **북마크 설치** — 설치 페이지의 버튼을 북마크바로 끌어다 놓는다.
2. **수집** — 경력개발센터(career.snu.ac.kr)에 로그인한 탭에서 북마크를 누른다.
   새 공고를 모아 `인턴공고_날짜_1ofN.md`(20건씩)와, 본문이 이미지뿐인 공고가 있으면 `포스터_날짜.pdf`를 만든다. 화면의 "받기"로 내려받는다.
3. **판정** — InternWatch GPT에 파일을 올리고 "판정해줘"라고 보낸다.
   처음이면 "기준 만들기"로 시작한다. GPT가 질문 7개로 기준 파일(`인턴 필터 기준.md`)을 만들어 주고, 다음부터는 이 파일을 공고 파일과 함께 올린다.

한 번 모은 공고는 다음 실행 때 건너뛴다. 처음부터 다시 모으려면 패널의 "본 공고 기록 지우기"를 두 번 누른다.

## 기준 인터뷰가 묻는 것

원하는 분야·직무 · 빼고 싶은 직무 · 근무지 · 학적 · 근무 시기 · 회사 규모를 볼지 · 점수 기준.

학적은 졸업예정자·기졸업자·석사만 받는 공고를 어떻게 할지 고른다.

| 선택 | 동작 |
|---|---|
| 빼기 | 제외한다. 단 "휴학생 가능"처럼 재학생도 받는 단서가 있으면 직접 확인으로 둔다 |
| 표시만 | 직무로만 판정하고 추천 표의 자격 칸에 `⚠ 졸업예정자·기졸업자`처럼 표시한다 |

## 판정이 맞는지 확인한 방법

2026-10-26에 모은 공고 40건에 사용자가 직접 관심·애매·없음 라벨을 붙이고 GPT 판정과 비교했다(GPT 판정을 보기 전에 라벨링).

| 학적 설정 | 관심 17건 중 추천 | 직접 확인 | 놓침 | 관심 없는데 추천 |
|---|---|---|---|---|
| 빼기 | 8 | 3 | 6 (모두 졸업예정자·석사 한정 공고) | 0 |
| 표시만 | 13 | 3 | 1 | 1 |

- GPT가 공고를 빠뜨리지 않게, 파일 머리의 id 수와 판정한 id 수를 맞춰 보는 검사 줄을 답 끝에 반드시 쓴다. 81건을 한 번에 판정한 시험에서 81/81이 일치했다.
- 본문이 이미지뿐인 포스터형 공고는 전체의 약 26%였다. 포스터를 잘라 PDF로 붙이자 직접 확인이 19건에서 7건으로 줄었다.

## 개인정보

- 스크립트는 내 브라우저 안에서만 돈다. 경력개발센터 페이지와 공고에 실린 포스터 이미지를 불러올 뿐, 어디로도 데이터를 보내지 않는다.
- 이미 본 공고 id와 마지막으로 만든 파일은 그 브라우저의 localStorage에만 남는다.
- 파일을 GPT에 올리는 건 사용자가 직접 한다. 기준 파일에는 이름·학번을 적지 않는다.

## 한계

- 경력개발센터 페이지 구조가 바뀌면 수집이 깨진다.
- GPT 판정은 틀릴 수 있다. 지원 전에 공고 원문을 확인한다.
- 판정은 ChatGPT Edu(서울대 계정) 공유 GPT로 한다.

## 파일

| 경로 | 내용 |
|---|---|
| `collect.js` | 수집 스크립트. 북마크가 jsDelivr에서 태그 고정 버전을 불러온다 |
| `index.html` | 북마크 설치 페이지(GitHub Pages) |
| `gpt/instructions.md` | 공유 GPT 지침 전문 |
| `gpt/기준 템플릿.md` | GPT 지식 파일 — 기준 파일 예시 |
| `tests/` | 파서 테스트 20개 |

## 개발

```
node --test tests/collect.test.js
```

- 파서는 개인용 Python판 InternWatch(비공개)를 옮긴 것이다. `tests/golden.json`은 같은 HTML을 Python판으로 파싱한 결과이고, JS 파서가 이것과 같은지 본다. `make_golden.py`는 Python판이 있어야 돈다.
- `tests/fixtures/`의 목록·상세 HTML은 실제 페이지 사본이다. 이름·학번·보안 토큰은 지웠다. `detail_poster.html`과 `tile_*.jpg`는 합성 픽스처다.

코드와 GPT 지침은 Claude(Anthropic)로 작성했다. 공고 판정은 ChatGPT Edu 공유 GPT가 한다.
